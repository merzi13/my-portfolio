Projects

Responsive Travel Website

A responsive landing page for a fictional travel company. The layout adapts to mobile, tablet and desktop using CSS Grid and Flexbox.

  • Hero section with background image and call-to-action button.
  • Destination cards arranged in a responsive grid.
  • Mobile-friendly navigation menu.

Technologies: HTML5, CSS3 (Flexbox & Grid)
What I learned: How to structure a landing page and make it look good on different screen sizes.

Recipe App UI

A clean user interface for a recipe website. Each recipe card shows a photo, cooking time and difficulty level.

  • Card-based layout for recipes with thumbnail images.
  • Typography and colour choices focused on readability.
  • Simple category bar for filtering recipes by type.

Technologies: HTML, CSS, Google Fonts
What I learned: How to design consistent cards and use spacing, borders and shadows to create a modern UI.

Parallel API Data Fetch

In this JavaScript assignment I built a function that loads user data in parallel using async/await and Promise.all. Instead of waiting for each request one by one, the app sends multiple requests at the same time.

  • Fetches user profile and posts in parallel.
  • Then fetches comments for all posts using Promise.all.
  • Measures total time and logs how much faster parallel fetching is.

Technologies: JavaScript (ES6), async/await, Promise.all
What I learned: How to speed up network calls by running them in parallel instead of sequentially.
